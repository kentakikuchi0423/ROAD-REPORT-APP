# 最初の ChatGPT プロンプト

愛媛県四国中央市の道路の破損の補修を依頼するための、LINEのチャット上で動くアプリケーションを Claude Code を用いて作成したいです。
以下の作成ステップに従って進めます。現在は Step1 です。

■作成ステップ
Step1. ChatGPT：
全体の構成整理、および Step2 で使うための入力プロンプトを作成する ← Now

Step2. ChatGPT：
新規チャットにて、Step1 の内容を受けて、Claude Code 用の
・作成手順
・実行プロンプト
・ユーザ確認観点
を作成する

Step3. Claude Code：
Step2 の指示に従い、Claude Code にてバイブコーディングでアプリを作成する

■アプリの要件

●目的
道路の破損の補修を依頼するためのアプリ

●前提
本アプリは、LINEのチャット上でユーザと対話しながら利用されるアプリケーションとする。
構成検討においては、LINE公式アカウント、Messaging API、LIFF、LINEミニアプリ等の仕組みを適切に使い分けること。

●依頼までのフロー
① ユーザが LINE 上で該当の導線を選択する
② アプリが「道路の破損に関する通報を行う」旨のチャットを表示する
③ ユーザが「はい」を選択すると、以降の情報を順に収集する
　「いいえ」を選択した場合は通報を中止する

④ 収集する情報：
・破損の状況を近くから撮影した写真
・破損の状況を遠くから撮影した写真
・位置情報（マップ上で選択）
・撮影した日付
・補足事項
・氏名
・電話番号

●データ管理
入力された情報はアプリ管理者のみ閲覧可能とする

●公開条件
原則無料で公開する

■バイブコーディングにおける前提
・VS Code の dev container 内で作成する
・Step2 では最初に dev container 用の環境構築ファイルを作成する手順を含めること
・Claude Code の MCP、スキル、コマンド、サブエージェント等は必要に応じて活用する

・Claude Code の Auto mode が利用可能な場合は、読み取り・編集・検証・安全な補助コマンド実行には活用してよい
・ただし、以下の操作は Claude Code に実行させないこと：
　・git commit / push / merge
　・破壊的操作
　・本番環境へ影響する操作

・原則としてベストプラクティスに従い、保守性・可読性・拡張性の高いコーディングを徹底する
・適宜リファクタリングを行う

■Git 運用ルール
・各手順は、上から順に実行すれば目的のアプリが作成できるように記述すること
・各手順では、必要に応じて実行すべき git コマンドや確認コマンドも明示すること

・ただし、以下はユーザのみが実行する：
　・git commit
　・git push
　・git merge
　・ブランチの最終確定

・Claude Code には commit 操作を実行させないこと
・Claude Code は以下のみ実施する：
　・差分確認
　・テスト実行
　・コミットメッセージ案の提示

・各工程の最後にユーザ確認チェックポイントを設けること
・Claude Code はチェックポイントで停止し、確認事項を提示すること

■設計・実装方針
・LINEチャット上で完結する処理と、外部画面（LIFF等）で実施する処理を明確に分離すること
・写真送信、位置情報取得、フォーム入力の実現方法を具体的に定義すること
・管理者が閲覧するための仕組み（管理画面または代替手段）を設計に含めること
・無料公開を前提とし、低コストで運用可能な構成を優先すること

・氏名・電話番号を扱うため、以下を考慮すること：
　・アクセス制御
　・安全なデータ保存
　・最低限のセキュリティ対策

・保守性を重視し、以下も整理対象とする：
　・ディレクトリ構成
　・命名規則
　・責務分離
　・環境変数管理
　・テスト方針

■今回の依頼
以下の順序で対応すること：

本アプリが技術的に開発可能かを回答する
設計に必要な確認質問を複数提示する
Step1として以下を作成する
　・全体構成の整理
　・想定アーキテクチャ案
　・技術スタック候補
　・Step2で使用するプロンプト案

■出力時の注意
・Step1 の範囲のみ回答すること
・Step2 や Step3 の実作業は行わないこと
・不明点は質問として整理し、勝手に確定しすぎないこと

・Claude Code に渡す指示は、上から順に実行可能で、作業漏れが起きにくい形で構成すること
・Git 操作は「Claude Code が実行してよい操作」と「ユーザのみが実行する操作」を明確に分けること

・LINE上のチャットで実現する機能、LIFFやLINEミニアプリで実現する機能、管理者向けに別画面で実装する機能を整理し、それぞれの役割分担が分かるように構成すること。
